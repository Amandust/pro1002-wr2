## WR2 – Refleksjon

I dette prosjektet har jeg sett hvordan gode arbeidsvaner skaper felles
forståelse i et team. Dokumentasjon og en tydelig README gjør at andre
raskt skjønner hva koden gjør og hvordan den kjøres, uten å måtte spørre.
Automatiske tester fanger feil tidlig og gir trygghet når flere endrer på
samme kode. Versjonskontroll med Git og tydelige commit-meldinger gjør det
mulig å følge hvorfor ting ble endret, og å jobbe parallelt uten å tråkke
på hverandre. Par- og mob-programmering og peer review sprer kunnskap, så
ingen sitter aleine med ansvaret for én del. Til sammen gjør dette at koden
eies av teamet, ikke av enkeltpersoner.
